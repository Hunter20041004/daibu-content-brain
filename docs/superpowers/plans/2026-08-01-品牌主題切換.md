# 品牌主題切換 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不顯示 Streamlit 開發工具列的情況下，提供可存續、可鍵盤操作的呆一布深／淺色切換。

**Architecture:** `daibu.ui` 以純函式產生固定 HTML 控制項，`apply_styles` 將它注入側邊欄。控制項沿用 Streamlit 的 localStorage 主題鍵並另外保存跨頁偏好，因此原生元件與品牌 CSS 會一起切換。

**Tech Stack:** Python 3.11、Streamlit 1.60、HTML/CSS/JavaScript、pytest、Streamlit AppTest、playwright-cli。

## Global Constraints

- 保留 `.streamlit/config.toml` 的 `toolbarMode = "minimal"`。
- 不把使用者、資料庫或 LLM 內容插入可執行 JavaScript。
- 按鈕至少 44px 高，有文字、SVG、ARIA 與可見鍵盤焦點。
- 嚴格一次一個 Red → Green → Refactor；只操作 `/tmp` 測試資料庫與 port 8502。

```python
def test_apply_styles_places_theme_switcher_in_sidebar(monkeypatch):
    rendered = []
    monkeypatch.setattr(ui.st.sidebar, "html", lambda body, **kwargs: rendered.append((body, kwargs)))
    ui.apply_styles()
    assert "theme-switcher" in rendered[0][0]
    assert rendered[0][1]["unsafe_allow_javascript"] is True
```
