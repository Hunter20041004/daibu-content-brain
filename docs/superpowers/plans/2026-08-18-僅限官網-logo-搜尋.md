# 僅限官網 Logo 搜尋 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完全移除 Brandfetch，讓 Logo 搜尋只走已驗證官網；官網沒有安全候選時直接提供重新搜尋與手動上傳。

**Architecture:** 保留 `official_site → logo_discovery → logo_browser` 三段官方路徑，`logo_search` 只負責編排並回傳官方候選或 `official_assets` 錯誤。Streamlit 工作台仍顯示最多三張候選且一律等待人工確認；設定頁、環境範本、供應商 adapter、測試與現行文件不再保留第三方 Logo 服務。

**Tech Stack:** Python 3.11、Streamlit、SQLite、pytest、urllib／HTMLParser、Playwright／Chromium、Tavily。

## Global Constraints

- 只從已驗證的公司官網取得 Logo；官網沒有安全、可預覽的候選時直接手動上傳。
- 不使用任何第三方 Logo API，也不新增相關憑證、設定或網路請求。
- Tavily 只尋找公開官網網址，不提供或代理 Logo 檔案。
- 每張候選仍必須由使用者人工確認，搜尋與預覽不得寫入資料庫。
- 缺 Logo 只阻止輸出七張圖，不阻止產生文字草稿。
- 嚴格垂直 TDD：一次一個失敗測試，RED → GREEN → REFACTOR。
- 保留工作樹中尚未提交的 SUN 真實契約與 Moove 無 `type` script 修正。
- 不碰主工作樹的使用者修改；只在 `.worktrees/verified-logo-discovery` 執行。
