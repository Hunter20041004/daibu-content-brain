# 官方 Logo 高命中與身分驗證 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 先以公司脈絡辨認正確官網，再從官網靜態／動態頁面找 Logo，官網無素材時以已解析網域查 Brandfetch，最後一律由使用者確認才儲存與出圖。

**Architecture:** 新增獨立的官方網站解析器與 Brandfetch adapter，保留 `logo_discovery` 專注於官網素材擷取，再由 `logo_search` 編排三段流程與分階段錯誤。Streamlit 只暫存一次搜尋的網站證據及最多三張候選；既有 `assets.store_logo()` 仍是唯一正式寫入入口。

**Tech Stack:** Python 3.11、Streamlit、SQLite、pytest、urllib／HTMLParser、Playwright／Chromium、Tavily、Brandfetch Logo API、既有 SVG／PNG 驗證。

## Global Constraints

- 嚴格垂直 TDD：一次只寫一個失敗測試，親眼看到 RED，做最小實作轉 GREEN，再重構並維持綠燈，才進下一個案例。
- RED／GREEN 只跑目前測試檔或單一案例；一個 Task 收尾才跑該 Task 聚焦集合；全套只在最終收尾與合併後各跑一次。
- 官方網站解析與 Logo 素材擷取是兩個獨立關卡；不得以放寬 SVG／PNG 安全規則提高找到率。
- 不使用圖片搜尋，不猜未被官網引用的 Logo 路徑，不生成、重畫、去背或修改 Logo。
- Brandfetch 只能在官網靜態與動態擷取均無可用素材後呼叫，且只能使用已解析、證據充分的網域。
- Brandfetch 必須要求 404 fallback；lettermark、Brandfetch 預設圖、透明占位圖與 favicon 不得成為候選。
- 不論來源或信心高低，一律由使用者按「確認是官方 Logo」後才可寫入 `brand_assets`、正式 Logo 目錄或出圖。
- 候選只放在 Streamlit session state；失敗不得修改正文、來源、七頁草稿或正式資料庫內容。
- 沿用既有 2 MB、PNG 64–4096 px／800 萬像素／透明背景、SVG viewBox／寬高與安全屬性規則。
- `BRANDFETCH_CLIENT_ID` 只走 `.env` 或本次執行環境，不 hardcode、不 commit；外部服務只傳公司公開資訊或官網網域。
- 前端沿用現有內容工作台的卡片、字體、色票、間距、focus 與 reduced-motion；實作時套用 `frontend-design`、`emil-design-eng`、`ui-ux-pro-max`，視覺驗收套用 `playwright-cli`。
- 真實網路與瀏覽器測試使用 `/tmp` 資料庫；正式 `daibu.db` 不可作為測試資料庫。
- 不新增公司主檔或長期官網資料表；確認前的官網解析結果只存在 session。

```python
def render_site(url, *, timeout_ms=15_000, playwright_factory=sync_playwright):
    with playwright_factory() as playwright:
        browser = playwright.chromium.launch()
        page = browser.new_page()
        page.goto(url, wait_until="domcontentloaded", timeout=timeout_ms)
        page.wait_for_timeout(300)
        html = page.content()
        backgrounds = tuple(page.locator("header *, nav *").evaluate_all(BACKGROUND_JS))
        browser.close()
    return RenderedPage(html, backgrounds)
```

Use `try/finally` so the browser closes on timeout. `BACKGROUND_JS` returns only visible elements whose accessible description/class/id contains `logo`／`brand`, or whose element is inside the primary home link.

Use this exact return shape for the JavaScript boundary:

```python
BACKGROUND_JS = """
nodes => nodes.flatMap(node => {
  const style = getComputedStyle(node);
  const match = style.backgroundImage.match(/url\\([\"']?(.*?)[\"']?\\)/);
  if (!match || node.getClientRects().length === 0) return [];
  const description = [node.id, node.className, node.getAttribute('aria-label')]
    .filter(Boolean).join(' ');
  if (!/(logo|brand)/i.test(description) && !node.closest('a[href="/"]')) return [];
  return [[new URL(match[1], document.baseURI).href, description]];
}
"""
```

```python
@dataclass(frozen=True)
class LogoSearchContext:
    company: str
    title: str
    angle: str
    body: str
    sources: tuple[VerifiedSource, ...]


@dataclass(frozen=True)
class LogoSearchResult:
    site: OfficialSite
    candidates: tuple[LogoCandidate, ...]
    used_brandfetch: bool


class LogoSearchError(ValueError):
    def __init__(self, stage: str, user_message: str) -> None:
        self.stage = stage
        self.user_message = user_message
        super().__init__(user_message)


def find_candidates(context, *, site_resolver=official_site.resolve,
                    official_finder=logo_discovery.extract_candidates,
                    rendered_fetch_fn=logo_browser.render_site,
                    brandfetch_finder=brandfetch.fetch_candidates,
                    brandfetch_client_id=None):
    text_context = " ".join(
        value.strip() for value in (context.title, context.angle, context.body)
        if value.strip()
    )
    site = site_resolver(
        context.company,
        context=text_context,
        sources=context.sources,
    )
    official = official_finder(
        site,
        rendered_fetch_fn=rendered_fetch_fn,
    )
    if official:
        return LogoSearchResult(site, official, False)
    fallback = brandfetch_finder(
        site,
        client_id=brandfetch_client_id,
    )
    if fallback:
        return LogoSearchResult(site, fallback, True)
    raise LogoSearchError("brandfetch", "官網與 Brandfetch 都沒有可用 Logo；請手動上傳。")
```
