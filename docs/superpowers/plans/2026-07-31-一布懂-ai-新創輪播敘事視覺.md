# 「一布懂 AI 新創」輪播敘事視覺 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把既有七張 AI 公司輪播改成九宮格可辨識、以好奇開場、角色參與敘事且有七頁節奏的呆一布品牌成品。

**Architecture:** 保留 `CarouselDraft`、來源與 Logo 資料介面，讓 `render.py` 依頁型輸出 Hero／Editorial／Evidence 三種鏡頭和既有 mascot SVG，再由唯一 `ai-startup.css` 負責 1080×1350 固定畫布。Prompt 只改封面 heading 的寫法；Streamlit 仍顯示既有 PNG，但桌機雙欄、手機單欄。

**Tech Stack:** Python 3.11、Streamlit、HTML/CSS、bundled LINE Seed TW、既有 SVG mascot、Playwright Chromium、Pillow、pytest。

## Global Constraints

- 固定輸出 1080×1350，使用 LINE Seed TW 400／700／800。
- 系列名稱固定為「一布懂 AI 新創」；封面不得顯示產業分類與來源。
- 第 2–7 張來源在內容底部保留帶，字級至少 28px，文字對白底至少 4.5:1。
- Logo 只使用已確認官方資產，不改色、不變形、不新增 Logo 搜尋。
- 吉祥物只使用 `assets/mascot/` 的既有 SVG，不呼叫圖片生成服務。
- 不改 SQLite schema，不更動已存來源與證據，不判斷內容值不值得發。
- TDD 嚴格一次一個失敗測試；每個切片只跑當前測試檔，Task 收尾才跑全套。
