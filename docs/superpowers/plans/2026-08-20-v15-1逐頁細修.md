# 七頁貼文模板 v15.1 逐頁細修 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不改三家公司內容資料的前提下，恢復已核可封面、移除第 2 頁白洞、修正第 3–6 頁節奏與碰撞，並讓所有呆一布至少縮小 10%。

**Architecture:** 沿用 localhost 直接服務的 `multi-company-template-stress-v13.html` 與 `editorial-v15-contract.js`。每個使用者可見修正先新增一個瀏覽器契約並確認失敗，再以 v15.1 範圍 CSS／DOM 做最小修正；正式 Streamlit、SQLite、公司內容資料與產圖模板均不接入。

**Tech Stack:** 單檔 HTML、原生 CSS、原生 JavaScript、Playwright CLI、pytest。

## Global Constraints

- 所有頁面的呆一布寬度不得超過 v15 原尺寸的 90%。
- 第 1 頁恢復右側大型直式描邊企業名稱；右上角另設 Logo 區，原型以公司字標佔位。
- 第 2 頁深藍結論不得以絕對定位硬壓頁底。
- 第 5 頁「到」仍是無框、無底色的雙色字體本身。
- 第 6 頁主訊號使用深藍底與白字。
- 不修改 `companies` 內容物件、正式產圖模板、Streamlit 或 SQLite。
- 一次只寫一個失敗契約，綠燈後才做下一項。
