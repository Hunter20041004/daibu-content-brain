# AI 新創公司候選與自動文案 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 讓「AI 新創介紹」只建立可核對的公司候選，並讓使用者採用後可用可信來源產生一份 350–500 字繁體中文初稿。

**Architecture:** 內容系列用內部 `content_kind` 決定候選規則；LLM 輸出先經純函式比對本輪素材，再一次寫入合格候選。採用後由新的 copywriting service 串接既有公司研究，驗證初稿，再用單一 SQLite transaction 儲存來源與正文，確保失敗不改資料。

**Tech Stack:** Python 3.11、Streamlit、SQLite、pytest、Streamlit AppTest、Gemini/Groq 免費 provider、既有可信網域研究流程。

**Constraints:** 嚴格 Red → Green → Refactor，一次一個失敗測試；不可碰正式 `daibu.db`；畫面驗收只使用 `/tmp/daibu-workstation-redesign.db` 與 port 8502；任何前端完成宣告前做兩輪桌機與手機截圖自檢。
