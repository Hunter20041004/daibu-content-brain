# 官方 Logo 候選與正文可見性 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修正正文文字不可見，並在公司正文完成後自動找到一張只來自官方頁、經使用者確認才儲存的 Logo 候選，同時讓使用者先看七頁輪播草稿。

**Architecture:** `search_web()` 只負責找可能官網；新的 `logo_discovery` 純服務解析官網與品牌頁、下載並用既有 Logo 規則驗證。Streamlit 僅暫存候選並承接確認，正式資產仍由既有 `assets.store_logo()` 寫入。七頁草稿沿用既有研究與 LLM 管線，與 Logo 確認平行。

**Tech Stack:** Python 3.11、Streamlit、SQLite、pytest、Streamlit AppTest、urllib／HTMLParser、Tavily 免費搜尋、既有 SVG／PNG 驗證。

## Global Constraints

- 不使用圖片搜尋，不猜 Logo URL，只解析公司官網或官網連出的品牌／媒體頁。
- 未確認候選不得寫入 `brand_assets` 或正式 Logo 目錄。
- 只接受 HTTPS SVG 或透明 PNG；既有 2 MB、4096px、800 萬像素、64px、`viewBox` 與 SVG 安全規則不放寬。
- 一個 session 每題只自動搜尋一次；失敗可重試，永遠保留手動上傳。
- Logo 只擋 PNG，不擋正文與七頁草稿。
- 只用 `/tmp/daibu-workstation-redesign.db` 驗收，正式 `daibu.db` 不得改動。
