# 七頁貼文 v13 品牌一致性細修 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 建立獨立 v13 原型，保留 v12 第 1、5、7 頁核心構圖，重整第 2、3、4、6 頁，使七頁共用成熟、可辨認且不模板化的科技編輯視覺。

**Architecture:** 從 v12 複製 v13，沿用三公司資料、切換器與內容句子。新增 `refined-v13-contract.js`，以逐頁 DOM、幾何與文字可見性契約垂直推動每一頁改版；最後以三公司雙寬度與兩輪截圖驗收。

**Tech Stack:** 單檔 HTML／CSS／JavaScript、LINE Seed TW OTF、既有呆一布 SVG、playwright-cli。

## Global Constraints

- 不修改 v10、v11、v12、正式 Streamlit、SQLite、正式內容或正式產圖模板。
- 不改七頁順序與內容主旨，不新增日期、來源、頁碼或 hashtag。
- 七頁都保留呆一布；不新增生成圖片或外部字型。
- 每次只寫一個失敗契約，再做最小 DOM／CSS 實作轉綠。
- 至少兩輪 1280×800／375×812 截圖自檢。
