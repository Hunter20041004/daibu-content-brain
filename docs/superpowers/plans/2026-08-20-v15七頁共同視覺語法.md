# v15 七頁共同視覺語法 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 以同一套成熟編輯式視覺語法重做本機七頁輪播原型，並讓第 5 頁的「到」成為跨色面轉軸。

**Architecture:** 沿用 localhost 直接服務的 `multi-company-template-stress-v13.html` 與既有 `companies` 資料，只把版本升為 v15、替換七頁語意 DOM 與新增一組 v15 CSS override。`editorial-v15-contract.js` 逐頁鎖住結構、禁用舊 AI 模板元素、字級、邊界、角色位置與預覽器遮擋；正式 Streamlit 與產圖引擎不接入此原型。

**Tech Stack:** 單檔 HTML、原生 CSS、原生 JavaScript、Playwright CLI、pytest。

## Global Constraints

- 不修改 `companies` 的正文欄位、正式 Streamlit、正式產圖模板或 SQLite。
- 保留深藍、青色、珊瑚橘、紙白、LINE Seed 與每頁呆一布。
- 主標最多兩行；封面最多三行；換行不得拆開詞組。
- 不使用圓角卡片、橢圓流程、編號小標、標籤方格、漸層背景、玻璃或陰影。
- 一次只做一個失敗契約 → 最小實作 → 綠燈 → 下一個契約。
- 不新增套件或外部資源。
