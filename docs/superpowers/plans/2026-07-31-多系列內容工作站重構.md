# 多系列內容工作站重構 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 將呆一布前端改成多系列、四步驟、候選可比較且輪播依賴線性可理解的內容工作站。

**Architecture:** `daibu.workspace` 以純函式推導系列目前步驟、今日任務與輪播 readiness；Streamlit 頁面只根據狀態渲染。資料庫與外部服務保持原契約，視覺元件集中在 `daibu.ui` 與 `daibu.theme`。

**Tech Stack:** Python 3.11、Streamlit、SQLite、pytest、Streamlit AppTest、Playwright CLI。

## Global Constraints

- 嚴格垂直 TDD：一次一個 failing test → 最少實作 → 綠 → 重構。
- 不改 SQLite schema、LLM adapter、搜尋／驗證規則、Logo 規則或輪播 PNG 版型。
- UI 稱 `Theme` 為「內容系列」，程式與 DB 仍保留 `Theme`。
- 每畫面最多一個 primary CTA；所有文字組合對比 ≥4.5:1。
- 測試與手動操作只使用 `/tmp` DB 與 port 8502。
- 最終只保留 `.screenshots/desktop.png`、`.screenshots/mobile.png`。
