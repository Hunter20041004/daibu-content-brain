# 科技編輯雜誌輪播視覺重設 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立隔離的 v11 七頁輪播原型，把現有一般卡片模板重做成可套用三家公司、具有科技編輯雜誌辨識度的視覺系統。

**Architecture:** 以 v10 的公司測試資料、切換器、標題長度函式與呆一布資產為資料層，另建 v11 HTML 作視覺層。每一頁都有獨立 DOM 語意與 CSS 構圖；同一份瀏覽器契約腳本逐頁檢查禁止元素、必要元素、幾何關係與溢出，最後以 Playwright 對三家公司與兩種寬度做壓力測試。

**Tech Stack:** 單檔 HTML／CSS／JavaScript、LINE Seed TW OTF、既有 SVG 吉祥物、`playwright-cli`、brainstorm localhost server。

## Global Constraints

- 只新增 `.superpowers/brainstorm/31101-1787251453/content/multi-company-template-stress-v11.html` 與同目錄的原型契約腳本；正式 Streamlit、SQLite、正式產圖模板與內容資料不得修改。
- 保留深藍 `#102F3D`、紙白 `#FAFBF8`、青色 `#86CCD4`、珊瑚橘 `#EC9870`，單頁只允許一個主要強調色。
- 使用既有 LINE Seed TW 與 `mascot-point.svg`／`mascot-note.svg`，不新增外部字型、圖片 API、生成式插畫或付費服務。
- 禁止 bento grid、橢圓流程圖、膠囊標籤、hashtag 小方格、無功能圓形、漸層光暈、圓角卡片與柔和陰影。
- 不新增頁碼、日期、來源、hashtag、文案或 CTA；現有內容與七頁順序不變。
- 嚴格 TDD：一次只新增一個失敗契約，親眼看到紅，再寫最小視覺實作轉綠。
- 前端完成前至少兩輪 1280×800 與 375×812 截圖自檢；三公司 × 七頁 × 兩寬度共 42 個狀態必須 0 overflow、0 text clipping，console 0 errors／0 warnings。

```js
(() => {
  const visible = (selector) => {
    const node = document.querySelector(`#companyView ${selector}`);
    if (!node) throw new Error(`Missing ${selector}`);
    return node;
  };
  const assert = (condition, message) => {
    if (!condition) throw new Error(message);
  };
  window.runEditorialContract = (name) => {
    if (name === 'version') {
      assert(document.body.dataset.visualVersion === 'v11', 'v11 marker missing');
      return { name, version: document.body.dataset.visualVersion };
    }
    throw new Error(`Unknown editorial contract: ${name}`);
  };
  window.editorialContractHelpers = { visible, assert };
})();
```
