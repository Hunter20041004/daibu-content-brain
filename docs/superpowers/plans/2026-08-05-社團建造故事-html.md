# 社團建造故事 HTML Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付一份給幾乎不寫程式、主要使用 Vibe Coding 的社團組員獨立閱讀的單頁 HTML，讓讀者看懂呆一布內容工作站的問題、建造方法、系統資料流、真實迭代與可複製步驟。

**Architecture:** 成品是一個不讀取產品資料庫、不呼叫外部 API 的單檔 HTML。主文以語意化 HTML 呈現九章建造故事，CSS 負責呆一布品牌、響應式與列印版面，少量原生 JavaScript 負責閱讀進度、章節狀態、七步驟資料流與全頁評論；pytest 與 Playwright 驗證內容契約、互動、鍵盤與手機版面。

**Tech Stack:** HTML5、Tailwind CDN、原生 CSS／JavaScript、內嵌 SVG、pytest、Playwright、playwright-cli。

## Global Constraints

- 最終檔案固定為 `docs/2026-08-05-我怎麼用-vibe-coding-搭出呆一布內容工作站.html`。
- 成品是單檔 HTML，不新增 npm、Python 或外部服務相依。
- 視覺沿用呆一布色票：`#E9F6FF`、`#6FC1CC`、`#32738F`、`#0E0E2C`、`#F8C0A0`、`#FAFCFE`、`#C7E2EA`。
- 字體採 Figtree 與 Noto Sans TC；中文內文至少 16px，正文行高 1.65–1.8，桌機段落寬度不超過 72ch。
- 吉祥物取自專案既有 SVG 並內嵌；不產生新 Logo、不呼叫 ImageGen。
- 主文先講使用畫面與生活比喻；技術名詞第一次出現依「白話 → 定義 → 產品角色」說明，程式碼只放在可展開區塊。
- 已移除的守門線、來源分層與常青／時效分類只能出現在「後來移除」的歷史脈絡，不能寫成現有功能。
- 不放 API key、真實資料庫內容、本機絕對路徑或只在作者電腦有效的資產連結。
- 互動元件可用鍵盤操作、觸控高度至少 44px、焦點框清楚、正常文字對比至少 4.5:1。
- 動效只使用 `transform` 與 `opacity`，160–220ms，並尊重 `prefers-reduced-motion`。
- 完成前跑兩輪 1280×800 與 375×812 截圖；每輪剛好兩張，不重讀舊截圖。
- 實作不修改 Streamlit 產品功能、資料表、AI 指令、真實資料庫或外部 API。

```python
from html.parser import HTMLParser

REQUIRED_SECTIONS = {
    "problem",
    "collaboration",
    "system-map",
    "content-journey",
    "timeline",
    "testing",
    "lessons",
    "recipe",
}


class StoryParser(HTMLParser):
    def __init__(self):
        super().__init__()
        self.ids: set[str] = set()
        self.tech_terms: set[str] = set()
        self.removed_features: set[str] = set()

    def handle_starttag(self, tag, attrs):
        attributes = dict(attrs)
        if attributes.get("id"):
            self.ids.add(attributes["id"])
        if attributes.get("data-tech"):
            self.tech_terms.add(attributes["data-tech"])
        if attributes.get("data-removed-feature"):
            self.removed_features.add(attributes["data-removed-feature"])


def test_story_covers_system_history_and_newcomer_glossary():
    parser = StoryParser()
    parser.feed(HTML_PATH.read_text(encoding="utf-8"))
    assert REQUIRED_SECTIONS <= parser.ids
    assert {
        "Streamlit", "Python", "SQLite", "RSS", "Tavily",
        "Gemini", "Playwright", "TDD", "Mock", "契約測試",
    } <= parser.tech_terms
    assert {"守門線", "來源分層", "常青時效分類"} <= parser.removed_features
```
