# 六頁公司介紹輪播 v57 圖標與流程線精修規格

## 目標

以 v56 為不可變基準新增 v57，只修正使用者指出的三個視覺問題：第三頁半透明圖標分散、第三頁因果線視覺上偏左，以及第四頁同時使用虛線與箭頭造成連接語言重複。

## 核可方向

採用 A 方案：把既有三個半透明 SVG 全部集中到第三頁右側三張便利貼，一張一個。語意映射固定為：

1. 「現有流程」放循環圖標。
2. 「優化空間」放靶心圖標。
3. 「釋放價值」放成長圖標。

第 2 頁與第 5 頁不再顯示這兩個被移走的圖標。第三頁的大型淡珊瑚問號是頁面背景符號，不屬於這三個 SVG，維持原狀。

## 第三頁幾何

因果線維持珊瑚色虛線、三個節點圓點與向下箭頭，但整體向右微移。定位不以肉眼猜測絕對像素，而以「左側兩張脈絡便利貼的右邊界」與「右側三張流程便利貼的左邊界」形成的欄間空隙為基準；線中心落在空隙由左往右約 55%–65% 的位置。這會比純數學中點稍偏右，抵銷左側兩張大色塊造成的視覺重量，並直接回應使用者指出的偏左問題。

三個半透明圖標固定放在各自便利貼右下安全區，不能壓住標題、正文、便利貼掀角或黏膠層；尺寸與透明度沿用 v56 的視覺語言。

## 第四頁連接語言

保留兩個實線箭頭，分別連接「理解輸入 → 分析處理」與「分析處理 → 交付結果」。移除 `.schema-route::before` 產生的橫向虛線。三張流程卡、文字、配色與位置不變。

備援方案是保留虛線並移除箭頭，但箭頭具有明確方向性，較適合表達三段流程，因此不採用備援。

## 技術邊界與資料流程

- 新增 `company-neutral-seven-pages-sticky-57.html`，不覆蓋 v56。
- 只搬動既有 SVG DOM 並加入 v57 範圍化 CSS，不新增圖片、套件或外部服務。
- 所有 `data-content-key`、hidden 相容欄位、六頁角色與頁碼保持不變。
- 正式 Renderer、AI 提示詞、SQLite 與正式站不在本輪範圍。

資料流仍為：既有 `CarouselDraft` 內容鍵 → 六頁語意 DOM → v57 視覺排版 → 本機瀏覽器預覽。

## TDD 與驗收

依垂直切片完成：

1. 先寫圖標分配契約，在 v56 驗證失敗；再搬動三個 SVG，使第三頁三張流程便利貼各有一個、其他頁沒有這三個半透明 SVG。
2. 擴充幾何契約，在未移線的 v57 驗證欄間位置不符；再把線移到核可的視覺中線範圍。
3. 先寫第四頁單一連接語言契約，確認 v56 同時存在虛線與箭頭而失敗；再關閉虛線並保留兩個箭頭。

完成後跑全部原型契約、專案完整測試，以及兩輪 1280×800／375×812 截圖自檢。驗收重點為三個圖標完全位於各自便利貼、因果線明顯不再偏左、第四頁只剩箭頭、零文字碰撞、手機無水平溢位、console 零錯誤與零警告。

## 安全、成本與限制

本輪沒有資料寫入、外部 API、付費操作、新依賴或部署成本。v57 仍是本機視覺原型；即使通過原型驗收，也不代表正式自動產圖工具已切換到此版。
