# 六頁公司介紹輪播 v56 精修設計

## 目標

在不覆蓋 v55、不更動正式 Renderer、AI 提示詞或 SQLite 的前提下，依使用者九個瀏覽器標註精修第 2–6 頁。v56 必須維持公司中立、六頁結構、粉彩手帳材質與現有內容鍵相容。

## 使用者可見變更

### 文案

- 第 4 頁標題固定為「AI 扮演什麼樣的角色？」。
- 第 5 頁標題固定為「它怎麼實際改善現有流程？」。
- 第 5 頁右下便利貼標籤由「購買關係」改為「帶來的價值」。內文改為說明流程改善對使用者、主管與團隊工作的實際影響，不討論採購角色。
- 第 6 頁 CTA 只保留兩句：「追蹤呆一布 AI 共學實驗室」與「帶你看更多最新 AI 資訊」。不顯示原本的喜好提問、帳號佔位或下一家公司留言邀請。

### 內頁標題

- 第 2–5 頁標題使用同一組放大規則，視覺字級比 v55 提高約 8–12%。
- 標題區整體下移約 `1–2cqw`，但不得與角色、膠帶或下一個內容模組重疊。
- 長標題最多兩行；不得裁字、孤立單字或壓縮正文至低於既有可讀性門檻。

### 第 2 頁

- 定位圖「AI 產品 → 目標使用者 → 核心價值」與企業 Logo 區改為上下分離，不再共用重疊範圍。
- 定位圖、Logo、兩張公司資料便利貼與底部提問維持同一條左右基線。
- 底部仍需用到足夠畫布高度，不因拆開上方模組而產生新空洞。

### 第 3 頁

- 左右內容組整體往上移，填補標題與內容之間的過量空白。
- 右側三張便利貼放大文字比例，但三張仍等寬、依序排列且零重疊。
- 垂直軸線往右移，使它位於左右欄的視覺間隙中央；三個節點仍需對齊三張右側便利貼中心。
- 左欄兩張便利貼可同步調整高度，保持與右欄整體底部接近。

### 第 4 頁

- 三步流程與四張說明便利貼視為一個內容群組，整體上移並放大，填滿標題下方至頁碼上方的可用空間。
- 三步流程維持等寬；下方四格維持 2×2；流程箭頭不得穿過文字。
- 內容群組不得與放大後的兩行標題或右上角色重疊。

### 第 5、6 頁

- 第 5 頁保留使用前／產品介入／使用後與兩張摘要便利貼，只更新標題、右下摘要語意與必要的長標題安全間距。
- 第 6 頁 CTA 兩句垂直、水平置中；第一句為主句，第二句為副句。角色與頁碼留在右下，不得壓住文字。

## 技術結構

- 以 `.superpowers/brainstorm/3440-1787701682/content/company-neutral-seven-pages-sticky-55.html` 為不可變基準建立 `company-neutral-seven-pages-sticky-56.html`。
- 使用 v56 範圍化 CSS 覆寫調整幾何，避免回寫或污染 v55。
- 保留所有 `data-content-key`、`data-company-field`、隱藏相容欄位及六頁 `data-story-role`。
- CTA 的舊生成欄位仍隱藏保留；可見 CTA 改用固定品牌文字。

## 資料流與相容性

既有 `CarouselDraft` → 舊內容鍵完整載入 → v56 顯示六頁需要的內容 → 舊 why-care、產業分類與 CTA 生成欄位留在 hidden 相容區。這輪不刪 schema、不遷移資料，也不接正式 PNG Renderer。

## 驗收與測試

採 TDD 垂直切片：

1. 文案契約先在 v55 因舊標題、購買關係與舊 CTA 正確失敗，再讓 v56 轉綠。
2. 標題契約鎖定第 2–5 頁字級比例、向下位移、兩行上限、零裁切與零角色重疊。
3. 第 2 頁契約鎖定定位圖與 Logo 垂直分離。
4. 第 3 頁契約鎖定內容群組上移、右欄字級、軸線位置、節點對齊、等寬與零重疊。
5. 第 4 頁契約鎖定群組占用率、三步等寬、2×2 說明格與零碰撞。
6. 跑既有六頁結構、schema、密度、便利貼材質與 CTA 契約；因核可文案改變而失效的固定文字斷言只更新預期值，不放寬幾何門檻。
7. 至少兩輪 1280×800 與 375×812 截圖自檢。最終必須 `scrollWidth == clientWidth == 375`、六頁無自身 overflow、console 0 errors／0 warnings。
8. 完整 `pytest` 通過後才可合回 `main`、推送；本輪未改正式功能，因此不重啟正式 Streamlit 服務。

## 風險與備援

- 主要風險是標題放大後擠壓內容。優先移動內容群組並調整留白，不以縮小正文換空間。
- 若第 4、5 頁長標題在壓力內容下超過兩行，備援是縮短英文字眉寬度與上方間距，不改使用者指定的中文標題。
- 若第 3 頁放大正文後發生溢位，先調整便利貼高度與內距；正文最低比例仍遵守 v55 的 `1.55%` 畫布寬門檻。

## 非目標

- 不接入正式自動產圖流程。
- 不改生成提示詞、資料庫、正式模板版本或品牌設定。
- 不新增頁面、圖像、動效或新的內容欄位。
