# 品牌主題切換設計

## 目標

在 Streamlit 原生工具列維持 `minimal` 的前提下，於側邊導覽品牌區下方提供清楚可見的深／淺色切換。使用者切頁或重新整理後仍維持選擇，且所有 Streamlit 原生元件與呆一布自訂色票同步切換。

## 已核可方向

- 使用一個全寬文字按鈕，顯示目前模式與下一個動作，例如「目前：淺色模式／切換成深色」。
- 使用同一套線性 SVG 太陽／月亮圖示，不用 emoji；按鈕至少 44px 高，支援鍵盤與可見焦點。
- 延續現有 Figtree、青藍主色、實驗室點綴與圓角，不採用工具建議的橘色新色票，避免破壞既有品牌。
- 不恢復 Streamlit 工具列，避免把 Deploy、Clear cache 等開發操作露給日常使用者。

## 技術結構與資料流

`daibu.ui.apply_styles()` 讀取 `st.context.theme.type`，用純函式 `theme_switcher_html(mode)` 產生固定、可信任的 HTML／JavaScript，再以 `st.sidebar.html(..., unsafe_allow_javascript=True)` 放到側邊欄。

點擊時將 `Light` 或 `Dark` 寫入 Streamlit 自己使用的 `stActiveTheme-<pathname>-v2`，同時寫入 `daibuColorMode-v1` 作為跨頁偏好，接著重新載入。控制項會同步側邊導覽內所有已知頁面路徑；未來新頁面第一次開啟時，控制項會用全域偏好補上該路徑後只重載一次。

## 安全、錯誤與限制

- JavaScript 全部是固定字串，不插入使用者、資料庫或 LLM 內容；`unsafe_allow_javascript=True` 不接受外部輸入。
- 若瀏覽器禁止 localStorage，按鈕保留目前主題，不修改資料庫，也不影響內容操作。
- 切換需要一次頁面重新載入，換取 Streamlit 原生元件、圖表與自訂 CSS 完整同步；不做只改背景的半套 CSS 切換。

## 驗收

- 單元測試涵蓋淺→深、深→淺文案、ARIA、儲存鍵與 `apply_styles` 注入位置。
- `toolbarMode` 仍為 `minimal`。
- Playwright 在 8502 實點：淺→深→切到內容製作→重新整理，模式不遺失；再切回淺色。
- 兩輪視覺驗收各覆寫桌機 1280×800 與手機 375×812 截圖；兩種模式都檢查對比、焦點、44px 觸控與無橫向捲動。
