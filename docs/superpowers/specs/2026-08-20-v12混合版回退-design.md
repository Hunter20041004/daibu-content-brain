# 七頁貼文 v12 混合版回退

> 日期：2026-08-20  
> 狀態：使用者已選擇方案 1  
> 範圍：本機三公司視覺原型；正式模板、內容與 SQLite 不修改

## 產品結果

v12 只組合已被使用者明確比較過的兩個版本：

- 第 1 頁保留 v11 科技編輯海報封面。
- 第 2–6 頁完整回到 v10，不重新設計、不混入 v11 結構。
- 第 7 頁保留 v11 全寬問題區與橘色收尾帶。

這不是新的視覺探索，而是回復可信的中間閱讀秩序，同時保留已獲認可的兩端。

## 技術結構與資料流

以 v10 HTML 作為乾淨基底，建立獨立 v12。三家公司資料、切換器、標題斷行與第 2–6 頁 render 字串直接繼承 v10；只加入 v12 封面／結尾 DOM、專屬 CSS 與結構契約。

~~~text
v10 基底
  ├─ P2–P6 原封不動
  ├─ 移植 v11 P1
  └─ 移植 v11 P7
          ↓
      v12 本機預覽
~~~

## 驗收

1. P2–P6 必須使用 v10 的 open-post／strip-post 結構，且不存在 v11 的 profile-layout、problem-chain、mechanism-layout、result-layout、evidence-ledger。
2. P1 必須有 cover-word、cover-line、cover-copy。
3. P7 必須有 closing-thesis、closing-question、closing-ticker。
4. 三家公司、七頁、1280px 與 375px 共 42 個狀態無 overflow。
5. 每輪固定截桌機與手機各一張；至少兩輪，逐項檢查層次、留白、字體、配色、對齊、響應式、狀態與動效。
6. console 0 errors／0 warnings；正式 Streamlit 與 SQLite 無修改。

## 替代方案與取捨

- 在 v11 內回貼 P2–P6：改動較少，但多層 CSS 容易殘留，因此不採用。
- 全部回到 v10：最穩定，但會失去已認可的 P1／P7，因此不採用。

## 限制

v12 仍是本機原型。使用者核可混合版後，才能另外規劃如何搬入正式產圖模板。
