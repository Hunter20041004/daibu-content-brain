   日期，按鈕仍不可按 → 表單應能送出並在伺服器端驗證缺件。這是本輪唯一修改的

   操作應穩定產出符合 schema 的草稿，或不額外消耗額度即可重試。

1. **PR Newswire 的建議引文混入頁首雜訊並截斷半句** → 貼該新聞稿網址後按抓取，
   建議值從標題、Accessibility、導覽字樣開始，最後停在半個分享字樣 → 應優先抽
   `article` 正文，並在完整句號處截斷。
2. **手機預覽把七張順序排成奇數後偶數** → 375×812 查看七圖預覽，元素座標依序是
   `1、3、5、7、2、4、6` → 手機應維持 `1→7` 的單欄閱讀與上傳順序。

   但 `01-cover.png` 只見帳號署名 → 七張都應呈現實際引用來源，或規格明文說明封面

4. **來源與頁型小字在 IG feed 尺寸過小** → 把 1080px 圖縮到約 375px 寬，底部來源
   與頂端頁型接近小於 10px 的閱讀感受 → 最小資訊應在不放大的 feed 尺寸仍可辨識。
5. **第 4–7 張標題缺少主詞** → 跳著看「如何化繁為簡／帶來的改變／為什麼值得關注

6. **第 7 張大多重複前文** → 連續讀完七張，第 7 張除了互動邀請外沒有新增理解 →
   CTA 頁應用一句新的收束或明確問題，避免只把前六張再列一次。
